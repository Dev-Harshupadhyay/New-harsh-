## 🌟 Key Features & Architecture

- **🎨 Modern Luxury Design System**: Custom typography pairing using *Fjalla One* and *Gilroy*, featuring high-contrast black & white tones, glassmorphism elements, and an Angular Geometric 'H' monogram logo.
- **⚡ Smooth Locomotive & GSAP Motion**: Integrated Locomotive Scroll v4 with GSAP ScrollTrigger for parallax scrolling, mask text reveals, and dynamic mouse-follower cursor spotlight.
- **📱 100% Multi-Device Responsiveness**: Tailored layout adaptation with fluid typography across Mobile, Tablet, Laptop, and Desktop screens.
- **👤 Editorial Bio Section**: Features a floating location badge (`📍 Faridabad, India`), full-stack expertise cards, developer philosophy quote box, and stacked mobile action buttons (`MY CV` & `LET'S TALK`).
- **🛠️ Black & White Tech Skills Bento Matrix**: 5-domain categorization featuring interactive technology pill badges with direct visual indicators:
  - **(01) Frontend Architecture**: <img src="https://skillicons.dev/icons?i=react,nextjs,ts,tailwind,gsap" height="24" alt="Frontend Stack"/>
    * React, Next.js, TypeScript, Tailwind CSS, GSAP, Framer Motion
  - **(02) Backend Engineering**: <img src="https://skillicons.dev/icons?i=nodejs,express,java" height="24" alt="Backend Stack"/>
    * Node.js, Express.js, Java, REST APIs
  - **(03) Database Systems**: <img src="https://skillicons.dev/icons?i=postgres,mongodb,supabase,firebase" height="24" alt="Database Stack"/>
    * PostgreSQL, MongoDB, Supabase, Firebase
  - **(04) Testing & QA**: <img src="https://skillicons.dev/icons?i=postman" height="24" alt="Testing Stack"/>
    * Manual Testing, API Testing, Regression Testing, Postman, SDLC / STLC
  - **(05) DevOps & Tools**: <img src="https://skillicons.dev/icons?i=git,github,docker,vercel,linux" height="24" alt="DevOps Stack"/>
    * Git, GitHub, Docker, Vercel, Linux, Termux
- **🖼️ Full-Screen Lightbox Modal**: View high-resolution certificates with dark blur backdrop and `Escape` key controls.
- **📩 Interactive Contact Form**: Built-in client-side form submission handler with inline `#submit-success` confirmation card.
